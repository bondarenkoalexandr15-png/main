# Инвестиционный советник (read-only) для T-Invest API

MVP советника, который **анализирует портфель и даёт рекомендации, но не торгует**.
Подключается к брокерскому счёту через официальный **T-Invest API** (Тинькофф
Инвестиции) в режиме чтения.

> ⚠️ Не является индивидуальной инвестиционной рекомендацией. Инструмент носит
> аналитический характер и не совершает сделок.

## Почему T-Invest, а не БКС

У БКС нет публичного REST API для розничных клиентов — доступ только через
терминал QUIK (QLua / QuikPy) или выгрузку брокерских отчётов. У Тинькофф есть
документированный **T-Invest API** (gRPC + REST), с песочницей и, что важно для
советника, **токеном только на чтение**. Поэтому прототип построен на T-Invest.
При необходимости слой провайдера (`advisor/providers/`) можно дополнить
QUIK-коннектором для БКС, не меняя аналитику и рекомендации.

## Архитектура

```
providers/  →  analytics  →  recommendations  →  report
(источник)     (метрики)      (правила)           (markdown/текст)
```

- `providers/tinkoff_rest.py` — read-only клиент T-Invest REST API.
- `providers/mock.py` — демонстрационный портфель (без сети и токена).
- `analytics.py` — аллокация по классам активов, секторам, валютам; концентрация (HHI).
- `recommendations.py` — движок правил (ребалансировка, лимиты риска, диверсификация).
- `report.py` — отчёт в markdown или тексте.
- `config.py` — целевая аллокация и риск-лимиты (настраиваются).

Клиент использует **только методы чтения** (GetAccounts, GetPortfolio,
GetInstrumentBy). Торговые методы не вызываются.

## Установка

```bash
cd invest-advisor
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Демонстрация на встроенном портфеле (без токена и сети):

```bash
python -m advisor --mock            # текстовый отчёт
python -m advisor --mock --markdown # markdown
```

Реальный портфель (read-only токен):

```bash
cp .env.example .env    # впишите TINVEST_TOKEN
set -a && source .env && set +a
python -m advisor
```

Песочница T-Invest:

```bash
TINVEST_USE_SANDBOX=1 TINVEST_TOKEN=... python -m advisor
```

## Как выпустить read-only токен

Личный кабинет Тинькофф Инвестиций → **Настройки → Токены для API** →
создать токен → выбрать доступ **«только чтение»**. Храните токен как секрет,
не коммитьте в репозиторий.

## Настройка под свой риск-профиль

В `advisor/config.py` задаются `TargetAllocation` (целевые доли акций/облигаций/
фондов/кэша) и `RiskLimits` (пороги концентрации, дрейфа аллокации, кэша).
Значения по умолчанию — умеренно-консервативный профиль.

## Ограничения MVP / дальнейшие шаги

- Мультивалютные позиции сейчас берутся по номинальной стоимости в валюте
  инструмента; полноценная конвертация по курсу — следующий шаг.
- Рекомендации детерминированные (на правилах). Можно добавить слой LLM для
  объяснений на естественном языке поверх посчитанных метрик.
- Возможные расширения: исторические риск-метрики (волатильность, бета,
  Sharpe, max drawdown), Telegram-бот/веб-дашборд, QUIK-коннектор для БКС.
