# Гайд для новичка: тренировка торговли в песочнице T-Invest

Этот гайд — для тех, кто **никогда не торговал**. Мы будем учиться на
**песочнице (Sandbox)**: сделки идут по реальным ценам биржи, но на
**виртуальные деньги**. Потерять реальные деньги здесь невозможно.

> ⚠️ Это учебный материал, а не индивидуальная инвестиционная рекомендация.

## Часть 1. Базовые понятия (простыми словами)

- **Акция** — маленькая доля компании. Купил акцию Сбербанка → владеешь
  кусочком банка. Цена меняется каждый день.
- **Облигация** — ты даёшь в долг (государству или компании), а тебе платят
  проценты. Обычно спокойнее и предсказуемее акций.
- **Фонд (ETF)** — «корзина» из многих бумаг в одной. Купил один фонд —
  как будто купил сразу десятки компаний. Удобно для диверсификации.
- **Лот** — минимальная пачка для покупки. У одних бумаг лот = 1 штука,
  у других = 10 или 100. Купить можно только целое число лотов.
- **Тикер** — короткий код бумаги: SBER (Сбербанк), GAZP (Газпром),
  LKOH (Лукойл), YNDX (Яндекс).
- **Заявка по рынку (market)** — «купи прямо сейчас по текущей цене».
  Простой способ для старта. Есть ещё лимитная заявка («купи, только если
  цена опустится до X») — к ней перейдём позже.
- **Комиссия** — брокер берёт маленький процент с каждой сделки.
- **Диверсификация** — «неклади все яйца в одну корзину». Чем больше разных
  бумаг и секторов, тем меньше риск.

## Часть 2. Ключевые правила риска (запомни с самого начала)

1. Не вкладывай всё в одну бумагу (ориентир — не более ~10–15% на одну).
2. Не концентрируйся в одном секторе (например, только нефтянка — рискованно).
3. Держи часть в облигациях/деньгах — это «подушка» на просадках.
4. Думай на годы, а не на дни. Частая суета обычно вредит новичку.
5. Сначала — только песочница. Реальные деньги — когда уверенно освоишься.

## Часть 3. Практика: команды тренажёра

Все команды запускаются так (токен уже в `TINVEST_TOKEN`):

```bash
cd invest-advisor
python -m advisor.trainer <команда>
```

| Команда | Что делает |
|---|---|
| `open` | создать виртуальный счёт |
| `fund 1000000` | пополнить на 1 000 000 виртуальных ₽ |
| `quote SBER` | узнать цену и размер лота |
| `buy SBER 5` | купить 5 лотов Сбербанка по рынку |
| `sell SBER 5` | продать 5 лотов |
| `portfolio` | показать портфель и свободные деньги |
| `operations` | история сделок |
| `analyze` | анализ портфеля советником (риски, перекосы) |
| `reset` | стереть песочницу и начать заново |

### Первое занятие (пошагово)

```bash
python -m advisor.trainer reset          # чистый старт
python -m advisor.trainer fund 1000000   # виртуальный миллион
python -m advisor.trainer quote SBER     # посмотреть цену
python -m advisor.trainer buy SBER 10    # купить немного
python -m advisor.trainer portfolio      # что получилось
python -m advisor.trainer analyze        # что советует советник
```

### Учебное задание №1: собрать сбалансированный портфель

Цель — потренировать диверсификацию. Из виртуального миллиона собери примерно:
- ~50% в 4–5 разных акциях (разные секторы: банк, нефть, IT, металлы);
- ~35% в облигациях/фонде облигаций;
- ~10% в фонде акций (ETF);
- ~5% оставь деньгами.

Потом запусти `analyze` и посмотри, что советник скажет про баланс. Правь
портфель, пока предупреждений не станет меньше.

## Часть 4. Что дальше

- Разберём чтение отчёта `analyze`: аллокация, концентрация, индекс HHI.
- Добавим лимитные заявки и понятие «стоп-лосс».
- Научимся смотреть на доходность позиций и вести портфель во времени.
- Когда будешь готов — перейдём с песочницы на реальный счёт (тот же токен,
  но уже без `--sandbox`, и с осторожными суммами).
